## Getting Started

### Prerequisites

- Git
- Node.js (v14 or higher)
- npm or yarn package manager
- Modern web browser

### Installation

```bash
# Clone the repository
git clone https://github.com/phsmartswb-ai/VendingMachine.git

# Navigate to project directory
cd VendingMachine

# Install dependencies
npm install

# Install yarn dependencies (if using yarn)
yarn install
```

### Running Locally

```bash
# Start development server
npm start

# Build for production
npm run build

# Run tests
npm test
```

## Deployment

### Netlify Deployment

The project is deployed on Netlify with automatic CI/CD pipeline.

**Live URL:** [https://snapvend.netlify.app/](https://snapvend.netlify.app/)

#### Deploy Steps

```bash
# Build the project
npm run build

# The build output is automatically deployed to Netlify
# via GitHub webhook integration
```

#### Environment Variables

Create a `.env` file in the root directory:

```env
REACT_APP_API_URL=https://api.snapvend.in
REACT_APP_ANALYTICS_ID=your_analytics_id
REACT_APP_PAYMENT_KEY=your_payment_key
```
